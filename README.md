# Azure Cloud Security Assessment & Remediation

## Executive Summary

**Enterprise Azure governance remediation project focused on IAM security, Key Vault governance, resource governance remediation, and backup resilience.**

Performed an enterprise Azure cloud security assessment focused on IAM governance, Key Vault security, resource group remediation, and backup resilience to identify misconfigurations, enforce least privilege, strengthen governance controls, and improve operational security posture.

## Project Overview

Conducted a cloud security assessment and governance remediation project within a Microsoft Azure enterprise environment to identify misconfigurations, strengthen governance, improve role-based access control (RBAC), enforce least privilege, correct departmental resource separation, secure Azure Key Vault implementations, and configure backup and recovery protections. This project focused on evaluating cloud security posture, correcting security architecture gaps, and improving compliance alignment through Azure governance modernization.

## Objectives

- Perform a full cloud security assessment of Azure infrastructure and resource governance  
- Identify security misconfigurations affecting confidentiality, integrity, and operational security  
- Evaluate role assignments and access control weaknesses across departments  
- Correct improperly assigned Azure resource groups and departmental boundaries  
- Strengthen least privilege and RBAC enforcement  
- Secure Azure Key Vault configurations through proper departmental segregation and access policy validation  
- Assess backup and recovery capabilities for business continuity and resilience  
- Validate Recovery Services Vault deployment and backup policy implementation  
- Improve enterprise cloud governance, operational readiness, and regulatory alignment  
- Reduce security risk exposure through remediation of configuration and governance weaknesses  

## My Role

- Assessed Azure resource groups for departmental misalignment and governance issues  
- Identified improperly assigned Key Vault resources across Accounting, Marketing, and IT departments  
- Corrected resource group assignments to restore organizational separation of duties  
- Evaluated IAM role assignments and strengthened role-based access controls  
- Validated departmental Key Vault access policies to enforce least privilege  
- Remediated Azure Key Vault placement for Accounting, Marketing, and IT resources  
- Assessed VM backup eligibility and identified unmanaged disk limitations for unsupported systems  
- Implemented Azure Recovery Services Vault deployment for supported virtual machines  
- Configured and validated backup policies for operational resilience and disaster recovery  
- Documented unsupported backup scenarios, technical limitations, and governance remediation priorities
- Applied enterprise cloud governance principles to improve security posture

## Key Security Findings

- Key Vaults were assigned to incorrect departmental resource groups  
- Departmental resource segregation failures increased risk exposure  
- Improper RBAC boundaries created governance weaknesses  
- Access control design required remediation to enforce least privilege  
- Backup limitations existed for unmanaged disk virtual machines  
- Only supported workloads could be protected under enhanced backup policy  
- Governance gaps impacted compliance, resilience, and operational security  
- Misconfigured cloud resources increased organizational security and governance risk 

## Remediation Actions Performed

### Resource Governance:
- Reassigned Marketing Key Vault to Marketing resource group  
- Moved Accounting Key Vault to Accounting resource group  
- Validated IT/Finance Key Vault placement within IT resource group  
- Restored departmental resource ownership boundaries  

### Access Control:
- Verified Marketing group retained proper Marketing Key Vault permissions  
- Verified Accounting group retained proper Accounting Key Vault permissions  
- Verified IT group retained proper IT/Finance Key Vault permissions  
- Strengthened least privilege through proper access policy governance  

### Backup & Recovery:
- Evaluated VM protection compatibility  
- Identified unmanaged disk constraints for Accounting and IT VMs  
- Successfully deployed backup for supported Marketing VM  
- Configured Recovery Services Vault and backup policy  
- Validated backup readiness and business continuity posture
